# AIM Network — MCP & Agent Registry Guide

Instruktioner och länkar för att registrera AIM Network på ledande kataloger för autonoma AI-agenter och MCP-klienter (Cursor, Windsurf, Claude Code, PayAI).

---

## 1. Smithery.ai (Största MCP-registret)

Smithery är standardkatalogen för Model Context Protocol (MCP). När du listar repot här blir AIM Network installerbart med ett enda klick i Claude Desktop, Cursor och Windsurf.

- **URL:** [https://smithery.ai/publish](https://smithery.ai/publish)
- **Repo:** `https://github.com/Johnmannen/aim-network-m2m-hub`
- **Konfigurationsfil:** `smithery.yaml` (finns i repots rot).
- **Steg:**
  1. Gå till [smithery.ai/publish](https://smithery.ai/publish) och logga in med GitHub.
  2. Välj repot `Johnmannen/aim-network-m2m-hub`.
  3. Smithery läser automatiskt `smithery.yaml` och verifierar `https://johngarp.click/mcp`.
  4. Klart! Servern listas publikt med verktygen `get_free_market_teaser`, `get_crypto_pulse`, `get_base_dex_radar`, och `get_deep_market_report`.
